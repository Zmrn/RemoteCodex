## 本次更新

- 图片预览支持图片内双指缩放、单指拖动、双击放大或复位；Windows 支持鼠标拖动和滚轮缩放。操作只影响图片，工具栏与应用页面保持原尺寸；关闭后页面原有缩放可用。
- 改善断开远程桌面后无法拉取会话的问题。官方总列表超时后，先从当前核对过的官方本机索引读取可确认的 Codex 任务，并提示列表可能不完整；合并并发请求、失败后退避，避免持续堆积读取。
- 列表失败时保留已显示内容和草稿，部分 Codex 列表不会清空已显示的 Chat 行。连接诊断新增最近实际列表读取结果，区分连接正常与列表可用；恢复后自动清除提示。

**请同时更新目标电脑的 Windows 接入端，以及使用的 Windows／Android 控制端。** 设备、密钥和草稿存储格式保持，更新直接从 GitHub Releases 下载。

## 验证范围

开发阶段，公司电脑 Remote 0.10.36／官方 Windows x64 26.903.9818.0 在断开远程桌面时，总列表60.218秒超时，其他接口与已关注正文仍可读；重新连接后同列表0.413秒恢复。仅确认本次关联，未定位官方内部挂起分支，也未修改官方后台调度。Chat 完整列表、实时状态和发送仍依赖对应官方接口，不能用磁盘索引授权写入或推断蓝点。

图片手势经过共享界面的真实浏览器触摸输入回归；本轮不安装或运行 APK，由用户更新后验证。最终版本测试及安装包验证结果见发布记录。

兼容性按当前实际接口逐功能判断。已知官方26.908.4834.0的会话设置接口升至v2，本版尚未适配，因此修改会话设置及新建时指定权限暂不可用；其他功能按各自接口判断。

Chat列表与文字历史保持，文字续写待专用真实验证；普通Chat新建、模型、生成图片及Work未完成适配未纳入本版。历史行为验证版本与详细范围由下方中央清单生成。
