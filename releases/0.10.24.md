# Remote Codex 0.10.24

新增「连接诊断」：从侧栏或问号菜单选择设备，分层查看配置、网络、鉴权、桥接、官方连接及版本能力，提供重试、编辑与脱敏复制。检测只读，不发送任务或修改网络；超时不会被描述为已经确认的单一故障。

修复设备删除后草稿误入另一台设备，旧草稿与原图单独保留并由用户明确恢复。Android 设备存储增加带校验的独立提交历史和文件锁，保存失败明确报错；原配置及加密身份保持。修复通知把未知显示成 0/0、官方统计尾部任务长期漏查、关键配置损坏导致启动失败。配置异常时保留原文件并保护写入，避免错误恢复或重复提交。

官方支持仍为 Windows x64 OpenAI.Codex **26.901.6511.0、26.903.8094.0** 的既有 Codex 核心功能。官方未读快照仅验证 **26.903.8094.0 本机 Codex、官方独占 broker**；其他版本、Chat、Work 未读无法确认时为未知。Chat 列表和文字历史可用、续写实验性，普通新建/模型/生成图片未完成；Work 未独立验证。VS Code 共存证据仍限原设备 26.903.8094.0 + VS Code 1.136.2 + Codex 扩展 26.903.61454，本次未复测该组合。

验证包括故障注入、真实本地 HTTP、共享界面、Node、主机 JVM、隔离 Windows 强制重启、双端构建/签名及 EXE 包内自检，以最终发布记录为准。本次不向用户官方任务写入。按用户安排不安装或运行 APK，手机的存储迁移、组件和后台行为由用户更新后验证。历史草稿没有地址指纹时只能按设备 ID 保护；同盘副本不能保证整盘或整个数据目录丢失后的恢复。详情见 CONNECTION-DIAGNOSTICS.md。
