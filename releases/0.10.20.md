# Remote Codex 0.10.20

切换 Codex / Chat 模式或当前设备时，侧边栏保持原来的展开/收起状态，只关闭对应的选择菜单。自动恢复上次任务、连接失败、恢复连接及迟到响应都不会强行收起或重新展开侧栏。Windows 窄窗口和 Android 共用该行为。

主动选择任务、新建对话、小组件跳转任务，以及关闭按钮、遮罩和返回键仍保留原有收起行为。侧边栏覆盖正文期间不生成已读回执；关闭侧栏后再按实际可见的最新回报判断已读。设备配置、密钥和原有已读数据格式保持不变。

## 验证与范围

共享界面在390×844竖屏及844×390横屏的模式/设备切换、任务恢复、草稿隔离、失败重连、手动关闭与迟到响应、侧栏遮挡已读和小组件跳转检查；原设备切换与已读回归，Node回归、Windows窗口检查、最终EXE自检、双端构建/签名/原Android证书与兼容清单核验。按此前用户安排，不安装或运行APK，由用户更新后验证手机实际交互；浏览器测试不是APK实机测试。

支持官方 Windows x64 OpenAI.Codex **26.901.6511.0、26.903.8094.0** 的 Codex 核心读写，具体限制以兼容清单为准。Chat 列表/历史支持，文字续写尚待真实专用任务验证；Chat 新建、模型切换、图片未支持。Work 未独立验证。

VS Code 共享 broker 真实写入证据仍限原开发设备的官方 **26.903.8094.0 + VS Code 1.136.2 + Codex 扩展 26.903.61454**；本机为官方独占 broker。本版未接入官方应用的已读状态；在官方应用中读过的旧回复仍可能计入 Remote Codex 未读。
