# Remote Codex 0.10.40

新增额度历史，并改进逐条回复的时间显示。

- 额度旁新增历史按钮；可选目标设备，查看最近 1、7、30 天的周额度、5 小时额度及有记录的独立模型额度。
- 记录保存在目标 Windows 设备本地，每 5 分钟采样，只保留最近 365 天。打开历史时按需读取；无记录的时段不补造数据，设备退出或关机期间不采样。
- 每段 AI 回复优先显示官方记录的逐条“开始接收”时间；缺少该时间时保留官方“记录于”时间或显示未知。

目标 Windows 接入端与使用中的 Windows/Android 控制端需一同更新。历史从目标设备更新并运行后开始积累，不补回升级前的数据。

沿用按功能检查官方接口的兼容策略。最近官方 Windows x64 26.908.9136.0 已完成只读连接、逐条时间和额度保存读取验证；不代表所有写操作实测。官方会话设置 v2 仍待适配，修改会话设置、新建指定权限暂不可用。Chat 普通新建、图片发送及未完成的 Work 适配未纳入。

APK 与 EXE 由同一次 GitHub Actions 构建，沿用原有签名与 GitHub 直接更新渠道。
