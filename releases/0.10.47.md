本版首次提供独立安装的 Limit Remote Codex，同时保留完整版。GitHub 同次生成完整版和 Limit 版的 Windows EXE、Android APK，共四个安装文件；两版的本地设备、密钥、草稿和更新通道分开，可在同一设备并存。

在目标电脑的完整版 Remote Codex 中开启远程接入后，可为一组 Limit 客户端生成受限配对码。使用同一码的 Limit 客户端共享自己创建的会话；不同配对码相互隔离。目标端按配对身份核对会话列表、内容、图片、附件及操作，可更换码并保留原会话，或撤销该身份。Limit 版只能连接远端，不能操作本机官方应用；不能查看或选择项目，只能新建无项目会话。无项目会话内的正常工具权限不额外收紧。

额度历史的 1 天视图增加本地日期分割线，更容易区分每天的记录。历史仍只展示实际采集到的点位，不补造缺失数据。

使用 Limit 版前，请先将目标电脑的完整版 Windows 接入端更新到本版。完整版和 Limit 版使用各自的更新清单与安装包；旧版不会自动变为 Limit 版。官方 Windows x64 26.915.4065.0 的兼容范围仍按现有接口逐功能判断，本版不扩大 Chat/Work 的未完成能力。按既有安排，不在发布过程中执行 APK、升级现有客户端或向既有任务发送测试消息。
