本版修复 Remote Codex 在会话接收窗口暂不可用时，消息看似提交却没有进入官方会话的问题。发送前现在必须拿到该会话新的官方 owner 状态；接收窗口不存在时明确提示消息未发送并保留草稿。提交结果未知时继续阻止自动重发，并提供“我已确认官方未收到，允许重新发送”操作；该操作只解除当前请求的防重记录，不会自行发送消息。

请同时更新目标电脑的完整版 Windows 接入端，以及使用中的完整版或 Limit 版 Windows／Android 控制端。四个安装文件同次构建、同版发布；两版保持独立安装和设备连接。Limit 版仍只能查看和操作同一配对码创建的无项目会话。

自动回归覆盖发送前 owner 丢失、草稿保留、结果未知时防重复提交与核对后的手动解除，以及桌面和手机界面。发布验证不向真实用户任务发送测试消息，也不执行 APK 或升级现有客户端。普通 Chat 新建、图片和未完成 Work 功能不在本版范围。
