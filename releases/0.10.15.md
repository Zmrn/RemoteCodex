本次更新加强 Windows 设备配置的持久化与升级保护，并修复与 VS Code 同时运行时的官方 ChatGPT 连接：

- 新增独立、不可覆盖的设备配置历史，保留原有稳定 ID 和 DPAPI 加密密钥。主配置与滚动备份同时损坏或回退时，从最新有效历史恢复；最新历史损坏或内容冲突时明确报错，禁止重置成默认列表。
- 启动前保全已有配置；重复选择当前设备不再重写主配置和备份。普通保存不能删除其他设备，也不能改动本次操作以外的设备；过期修订写入被拒绝。
- 升级助手在替换 EXE 前保存设备、接入和更新设置快照，启动后核对配置一致性；核对失败不能记作更新成功。此更新保护由 0.10.15 的升级助手执行，对升级到本版本前已经发生的丢失不作恢复承诺。
- Windows/Android 共用界面分别提示滚动备份恢复和独立历史恢复；Android 原生设备存储格式保持兼容。
- VS Code 先持有共享 IPC 管道时仍能连接官方 ChatGPT；分别验证官方工具进程与签名有效的 VS Code 转发进程，并按真实任务 owner 定向操作。文字、多图、设置、队列、查看重连、停止及原任务续写已在专用任务验证，具体组合和未验证项见 VSCODE-COEXISTENCE.md。

本次重点是正常启动、进程中断、配置回退和版本升级时的数据保护；不包含已丢失设备的重新配对。历史快照在同一磁盘，不能替代磁盘损坏或整个数据目录丢失时所需的外部备份。密钥和历史不会上传服务器或进入安装包。
