# Remote Codex 0.10.19

Android 2×2 小组件按桌面分配的尺寸居中显示正方形卡片，收起原来多出的高度，让可见尺寸更接近同格数的原生天气组件；横竖屏、调整大小和多个组件实例分别适配。使用与应用一致的深蓝灰背景、22dp 圆角，数字仍为橙色未读回报 / 蓝色运行中。

任务概览页按确认的设计重做：紧凑标题栏和刷新入口、深色分段切换、任务卡片、缓存标记、底部打开应用按钮及深色系统栏。可以筛选全部/单台设备，查看失联设备和统计详情；筛选仅影响本页展示，不切换已保存的设备，不停止其他设备同步，不修改设备配置或已读记录。

沿用全部设备独立持续同步和断线重连。官方列表上限、离线缓存、状态未知仍明确显示部分统计，不将失败显示为健康的零。

## 验证与范围

双端构建及签名、原 Android 安装证书和同版本兼容清单检查；Node 回归、Windows 窗口检查、主机 JVM 多设备连接恢复及组件尺寸/筛选/缓存/去重逻辑检查、共享界面已读与跳转/草稿回归。按用户此前安排，本轮不安装或运行 APK，由用户更新后验证手机桌面尺寸和原生页面；主机检查不等于 APK 行为验收。厂商启动器的格子与留白可能不同，不能承诺所有设备像素完全一致。

支持官方 Windows x64 OpenAI.Codex **26.901.6511.0、26.903.8094.0** 的 Codex 核心读写，具体功能限制以兼容清单为准。Chat 列表/历史支持，文字续写尚待真实专用任务验证；Chat 新建、模型切换、图片未支持。Work 未独立验证。
