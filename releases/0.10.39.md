# Remote Codex 0.10.39

修复会话偶尔离线、历史读取失败时无法继续输入的问题。

- 已有 Codex/Chat 会话仍可编辑和保存本地草稿，界面会提示当前无法发送。
- Codex 草稿图片可以离线选取、粘贴和移除；只添加图片也会触发草稿保存。
- 重连不会覆盖新输入，也不会自动补发。切换设备、会话和模式时，各自草稿继续隔离保存。
- 发送仍需当前官方连接、会话状态和对应接口支持；只读会话不能通过 Ctrl+Enter 绕过限制。

更新使用中的 Windows 或 Android 控制端后生效。初始草稿恢复和正在提交期间仍保留输入保护；官方尚未加载的会话可保留图片草稿，发送图片需先在官方打开该会话。

本版沿用按功能检查官方接口的兼容策略。官方会话设置 v2 仍待适配，修改会话设置、新建指定权限暂不可用。Chat 普通新建、图片发送及未完成的 Work 适配未纳入。

APK 与 EXE 由同一次 GitHub Actions 构建，沿用原有签名与 GitHub 直接更新渠道。
