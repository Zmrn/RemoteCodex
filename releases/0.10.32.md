## 本次更新

- 修复官方桌面升级后，接口检查正常却整机功能被禁用的问题。现在按实际使用的 20 项接口和 23 项功能依赖判断兼容性，版本号变化本身不再阻止使用。
- 个别接口异常只影响依赖它的功能。例如改名异常仍可发送，队列异常仍可使用 Ctrl+Enter 调整方向，停止操作独立判断。
- 列表、项目或模型目录读取失败不再使整个设备断线，也不阻止使用默认设置发送。官方工具与 owner 连接分别判断，帮助页报告与实际功能使用同一套规则。
- 继续核对官方进程身份、任务所有者、当前轮次及操作回执；连接切换后重新取得证据，发送结果未知不自动重试。任务状态、未读和已读仍以官方数据为准。

请更新目标电脑的 Remote Codex；Windows、Android 控制端也更新后可显示完整的逐功能兼容信息。设备、密钥、未发送草稿存储格式保持，更新直接从 GitHub Releases 下载。0.10.28 及更早版本需手动覆盖安装一次迁移，并保留原数据。
