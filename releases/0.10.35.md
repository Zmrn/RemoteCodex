## 本次更新

- 支持普通终端命令审批。Windows 和 Android 均可查看完整命令、理由与工作目录，并选择允许一次或拒绝；同格式的下载、终端操作共用处理流程。
- 官方提供类似命令规则时，支持“允许类似命令”，显示完整前缀范围并原样提交。批准后的状态继续同步官方，发送结果未知时不会自动重复批准。
- 每条用户消息、AI 回复和可见问答记录显示本地时区的日期及秒级时间。时间来自官方记录：单条完整消息标“记录于”，轮次时间标“本轮开始”，缺失时显示“时间未知”。
- 时间更新保持正文和已加载图片稳定；原有网站访问授权继续独立判断兼容性。旧控制端不会提供看不到完整命令的批准按钮。

**请同时更新目标电脑的 Windows 接入端，以及使用的 Windows／Android 控制端。** 命令审批需要两端都更新；消息时间共用页面，单条历史记录时间也需要接入端返回。设备、密钥和草稿存储格式保持，更新直接从 GitHub Releases 下载。

## 验证范围

本机官方 Windows x64 **26.903.9818.0** 的命令审批协议及真实只读接口已核对。286 项 Node 22.19.0 回归、新旧审批和共享界面的桌面／手机宽度检查通过。接口匹配不等同实际审批往返；本轮没有批准真实请求或执行申请中的命令，不安装或运行 APK，由用户更新后验证。

普通终端命令只有在官方提供可识别的前缀规则时开放“类似命令”。专用网络策略、文件修改、额外权限和未知新版选项属于其他协议，仍在官方应用处理。授权、消息、运行及已读状态以官方数据为准。

Chat 列表与文字历史保持；普通 Chat 新建、模型选择、生成图片及 Work 的未完成适配未纳入。兼容性按实际接口依赖逐功能判断；历史行为验证版本与详细范围由下方中央清单生成。
