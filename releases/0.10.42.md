# Remote Codex 0.10.42

提高 Windows 在死机、异常重启后的启动可靠性。

- 解压程序文件时逐文件请求落盘，完整校验通过后才启用缓存。
- 启动发现缓存文件缺失、截断或损坏时，从同一 EXE 的完整内置资源自动重建，无需手动删除缓存。
- 修复使用独立目录，保留损坏缓存和用户数据；之后启动复用已校验的恢复目录。
- 防止解压中途退出或多个进程同时启动导致使用不完整缓存；临时文件占用不会误判为损坏。
- 保留严格的资源哈希、路径和目录链接检查，不以跳过校验换取启动。

本次 Windows 接入端和控制端共用上述恢复能力，Android 同次发布以保持双端版本一致。无需重新配对。仍包含 0.10.41 的图片重试修复、下载进度及具体错误提示。

当前官方 Windows x64 26.911.7940.0 最近完成只读连接检查；按实际接口逐功能启用，不代表全部写操作实测。settings v2 仍待适配，修改会话设置和新建指定权限暂不可用。Chat 仅包含既有已完成范围，普通 Chat 新建/图片及未完成 Work 适配不在本版。

APK/EXE 由同一次 GitHub Actions 构建，沿用原签名与 GitHub 直接更新渠道。不执行 APK 真机测试，由用户更新后验证。缓存保护不能保证存储硬件在异常断电下绝对无损；EXE 自身损坏仍需重新下载。
