本版修复新建任务前选择“完全访问”，进入任务却显示“自定义权限”的问题。内置权限现在与官方一样同时设置访问范围、审批策略和审批者；完全访问使用 never/user，工作区和只读使用 on-request/user。已有任务切换权限也使用同一套设置。

新建前会核对权限准备任务的实际完整设置，修正旧准备任务残留的审批策略，确认官方生效后才创建任务。连接或确认结果不明确时停止创建，保留草稿，不自动重发。

请更新目标电脑的 Windows 接入端，建议控制端也保持同版，无需重新配对。官方 Windows x64 26.915.4065.0 已在源码阶段通过专用任务验证：复现旧设置组合、修正后首轮完整权限、Remote 重连及下一轮保持、切回只读恢复审批。此修复不承诺解决官方恢复老任务时丢失设置并回到默认权限的问题；未重启官方验证恢复行为，也不私存旧权限覆盖官方状态。

本次不扩展 Chat/Work：只包含原有已完成能力，普通 Chat 新建、图片和未完成 Work 适配未纳入。按约定不运行 APK/模拟器或升级现有客户端；发布验签、包内容与实际官方连接结果见仓库 GITHUB-UPDATES.md。
