# Markdown 显示检查

| 优先级 | 问题与影响 |
|---|---|
| 高 | 发送途中切走再切回，已发送文本仍留在输入框，再点击会重复提交 |
| 高 | 消息在真正发送前被拒绝，仍被记录为“结果未知”，导致原文重试一直发不出去；Codex、Chat 均复现 |
| 中 | 实时刷新会抢走问题回答框的焦点，打字被中断 |
| 中 | 未提交的问题答案没有持久化，更新或重开后会丢失 |
| 中 | 空闲 Codex 会话临时读取失败后不自动重试，保持“已连接”却无法输入 |
| 中 | Android 超过 6 MB 的结果图片无法下载，提示的附件入口也可能不存在 |
| 中 | 浏览过的会话没有取消订阅或快照回收，存在长期资源增长风险 |

这些是格式验证用的历史报告文字，不代表本版本修复范围。
